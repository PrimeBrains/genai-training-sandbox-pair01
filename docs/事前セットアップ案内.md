# 事前セットアップ案内（研修当日までに必ず完了してください）

対象: Windows PC（コマンドはすべて **PowerShell** で実行します）
所要時間の目安: 30分（ほとんどはダウンロード待ちです）

## 1. インストールするもの

**すべて下記のインストールコマンドで入れてください**（サイトからダウンロードボタンを探す方式は、別物を入れてしまう事故が起きやすいため使いません）。

| ツール | インストールコマンド（PowerShell） | 確認コマンド |
|--------|-----------------------------------|--------------|
| JDK 21 | `winget install EclipseAdoptium.Temurin.21.JDK` | `java -version` |
| Git for Windows | `winget install Git.Git` | `git --version` |
| GitHub CLI | `winget install GitHub.cli` | `gh --version` |
| Claude Code | `irm https://claude.ai/install.ps1 \| iex` | `claude --version` |

- ⚠ Claude Code は **claude.com のダウンロードボタンからは入れない**でください。あちらは Claude アプリ（チャット用）で、本研修で使う `claude` コマンドとは**別物**です。必ず上のコマンドで入れます
- Claude Code のインストール完了時に「`.local\bin` is not in your PATH」という警告が**ほぼ確実に出ます**（複数環境で確認済み）。次の1行を実行してから PowerShell を開き直してください:
  ```powershell
  [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:USERPROFILE\.local\bin", "User")
  ```
- 4つすべて入れ終わったら、**PowerShell を開き直してから**確認コマンドを実行してください（開き直さないと PATH が反映されず「認識されません」になります）
- Git for Windows は Git Bash を開く必要はありませんが、Claude Code が内部で使うため**インストールは必須**です
- `winget` が「認識されません」の場合のみ、公式サイトから手動インストール: JDK https://adoptium.net/ （Temurin 21 の **.msi**、**「Add to PATH」を有効**にする）/ Git https://git-scm.com/ / GitHub CLI https://cli.github.com/

## 2. GitHub の認証

```powershell
gh auth login
```

ブラウザが開くので、自分の GitHub アカウントでログインしてください。
（アカウントがない方は https://github.com/ で無料登録してから）

## 3. AI 利用キーの設定

研修運営から `genai-training-pairXX-credentials.txt` というファイルがペアごとに配布されます。
PowerShell で次を実行してファイルを開き:

```powershell
mkdir $env:USERPROFILE\.aws -Force
New-Item $env:USERPROFILE\.aws\credentials -ItemType File -Force
notepad $env:USERPROFILE\.aws\credentials
```

（`New-Item` を挟まず `notepad` だけで開くと、メモ帳が勝手に拡張子を補って `credentials.txt` を作ってしまい、設定が読み込まれません）
開いたメモ帳に、配布ファイルの3行を貼り付けて保存してください:

```
[genai-training]
aws_access_key_id = （配布された値）
aws_secret_access_key = （配布された値）
```

- これだけで Claude Code の接続設定は完了です（残りの設定はリポジトリに同梱済み）
- ⚠ このキーは研修専用・研修後に無効化されます。**他人に共有したり、リポジトリにコミットしたりしないでください**

## 4. 動作確認

あなた専用のリポジトリを clone してテストを実行します。
**clone する URL は、§3 で配布されたファイルの先頭に書いてあります**（`pairXX` の番号は人によって違います）:

```powershell
[Console]::OutputEncoding = [Text.UTF8Encoding]::new()
git clone （配布ファイル先頭に書いてある、あなた専用の URL）
cd genai-training-sandbox-pairXX   # ← 自分の番号に読み替え
.\gradlew.bat test
```

- 1行目はコマンド出力の文字化け対策です（ビルドやテストの日本語メッセージが化けるのを防ぐ。PowerShell を開き直したら再度実行してください）

- 初回は依存ライブラリのダウンロードで数分かかります（研修当日の時間節約のため、必ず事前に1回実行しておいてください）
- **`BUILD FAILED`（テスト失敗）と表示されたら成功です。** テストが落ちているのは仕様で、研修当日の課題です。直さないでそのままにしておいてください

最後に Claude Code の接続確認（同じフォルダの中で実行）:

```powershell
claude --print "接続テスト。10文字以内で応答して"
```

**結果の見分け方（何か表示された＝OK ではありません）:**

- ✅ 成功: 「接続OK」のような**日本語の短い返事だけ**が表示される（応答まで数十秒かかることがあります）
- ❌ 失敗: `API Error` や `Error` を含む行が表示される。よくある例:
  - `API Error: Could not load credentials from any providers` → §3 の貼り付け漏れ、またはファイル名が `credentials.txt` になっている（「うまくいかないとき」参照）
- エラーが出た場合は**完了ではありません**。「うまくいかないとき」を確認するか、スクリーンショットを添えて運営へ連絡してください

## 5. Copilot のログイン確認（研修前半で使います）

ブラウザで https://copilot.microsoft.com を開き、**会社の Microsoft アカウント**でログインできることを確認してください。
ログイン後、画面上部（「新しいチャット」ボタンの近く）に**盾マーク（企業データ保護）**が表示されていればOKです。個人の Microsoft アカウントでは保護が効かないので、必ず会社アカウントで。

- 盾が見当たらないとき: ページを再読み込みする / 右上のアイコンで会社アカウントか確認する / それでも出なければ https://m365.cloud.microsoft/chat から開き直す（初回は表示が遅れることがあります）

ここまですべて確認できたら完了です。

## うまくいかないとき

- 完了/未完了を、前日までに運営へ一言連絡してください（未完了でも当日サポートします）
- エラーメッセージのスクリーンショットを添えてもらえると当日の対応が速くなります
- よくある原因: 確認コマンドが「認識されません」→ PowerShell の開き直し / JDK の「Add to PATH」漏れ
- 接続確認で `Could not load credentials` → `Get-ChildItem $env:USERPROFILE\.aws` でファイル名が `credentials`（`.txt` なし）になっているか確認。`credentials.txt` になっていたら `Rename-Item $env:USERPROFILE\.aws\credentials.txt credentials` で直す
